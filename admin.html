Publish to GitHub

Push your saved changes to the live repo so everyone gets them (not just this browser). Paste a GitHub fine-grained token below — it is kept in memory for this session only, never saved to the page or the repo.

Token setup (one time): GitHub → Settings → Developer settings → Fine-grained tokens → Generate. Repository access: only Computer-Repair-Report-Generator. Permissions: Contents: Read and write (+ Metadata: read). Set an expiration. Then paste it here each time you publish.

Publishing commits to branch and updates both the root and diagnostic_generator/ copies of each file. Changes go live after GitHub Pages rebuilds (about a minute).
