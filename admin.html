Danger Zone — Delete Part Data

Delete the Richland 1 / Worth list and the FieldPower list independently, or wipe both. Deleting empties that catalog. Important: this only affects THIS device until you Publish — the generators read the repo file, so you must publish the empty catalog to make it gone for everyone. If your token is pasted on the Publish tab, delete will offer to publish for you.

Edit A5_FM_U_parts.json

Direct edit of the active database. Validate before saving. Saving writes to localStorage, which every Web Center tool reads first.

Parts Editor

View and edit every part for a model. Fix part numbers, change details, or add missing parts (e.g. a warranty number that isn't listed). Save writes to the Web Center; use the Publish tab to push live to all devices. Worth-Provided (W-) parts are highlighted green.

Resolve Preview

Confirms which number the Diagnostic Generator will pick for each canonical part on this model — ADP/Worth repairs vs. Warranty (OEM) repairs.

Verbiage Editor

Add, edit, remove, or reorder the diagnostic issue verbiage the generator shows. Changes save to the Web Center (localStorage) and can be downloaded as verbiage.json.

Suggestions Board

Ideas and bug reports from the Idea Box appear in Inbox. Promote good ones to Priority, mark them Done, or archive. Drag between columns or use the buttons.

Publish to GitHub

Push your saved changes to the live repo so everyone gets them (not just this browser). Paste a GitHub fine-grained token below — it is kept in memory for this session only, never saved to the page or the repo.

Token setup (one time): GitHub → Settings → Developer settings → Fine-grained tokens → Generate. Repository access: only Computer-Repair-Report-Generator. Permissions: Contents: Read and write (+ Metadata: read). Set an expiration. Then paste it here each time you publish.

Publishing commits to branch and updates both the root and diagnostic_generator/ copies of each file. Changes go live after GitHub Pages rebuilds (about a minute).
